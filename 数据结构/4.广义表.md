```c++
struct Triple {
    int row;
    int col;
    int value;
};

struct MatrixNode {
    int tag;              // 0表示Head，1表示Term

    MatrixNode* down;     // 指向同一列的下一个结点

    union {
        Triple term;      // Term结点使用
        MatrixNode* next; // Head结点使用
    } uregion;

    MatrixNode* right;    // 指向同一行的下一个结点
};
```//公共部分用普通结构体成员保存，不同的部分用 union 共享存储空间，再通过 Tag 区分当前结点类型。这其实是 C/C++ 中一种经典的“带标记的联合体”设计。你可以把它理解成：同一种结点外壳，里面根据需要放两种不同的东西。
