## 1.7 顺序表按值查找
（按照某一元素的值查找位置，不存在就返回0）
==🔵时间复杂度分析：找到执行次数最多的语句，计算执行次数，用大O表示法
ASL 平均查找长度（期望值)
```c++
int LocateElem(SqList L, ElemType e){
for (int i=0;i < L.length;i++)
	{
	if(L.elem[i]==e) {
	return i+1;//返回的是逻辑位置，比物理位置多1
		}
	}
	return 0;
}
```

## 1.8顺序表插入
(在第i个位置插入新元素，表长+1)
异常情况：1.插入位置不合法（0到n） 2.表满了
平均时间复杂度：(0+...+n)/(n+1)=n/2，O(n)
```c++
Status ListInsert(SqList &L,int i,ElemType){
	if (i<i || i> L.length+1 || L.length == MAXSIZE){
		return ERROR;
	}
	for(int j = L.length - 1;j <= i-1;j--)
	{
	L.elem[j+1] = L.elem[j];
	}
	L.elem[i-1] = e;
	L.length++;
	return OK;
}//Status返回的是操作状态
```

小结：

1.利用数据元素存储位置表示相邻数据元素的前后关系

2.顺序表有随机存取的特点

3.顺序表常用操作算法分析：

| 操作  | 时间复杂度 | 空间复杂度 |     |
| --- | ----- | ----- | --- |
| 查找  | O(n)  | O(1)  |     |
| 插入  | O(n)  | O(1)  |     |
| 删除  | O(n)  | O(1)  |     |

| 优点    | 缺点                 |
| ----- | ------------------ |
| 存储密度大 | 插入与删除麻烦            |
| 随机存取  | 浪费存储空间             |
|       | 静态存储，不能自由扩充数据元素的个数 |
