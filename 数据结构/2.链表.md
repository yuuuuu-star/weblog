1.定义：
用一组物理位置任意的存储单元来存放数据元素。
每个结点包括数据域和指针域。
第一个元素的地址叫做头指针，每个单链表由头指针唯一确定，因此可以用头指针命名。

3.头指针：指向第一个结点的指针
头结点：头指针指向的，首元结点前的结点
首元结点：链表中存储第一个数据元素的结点

不带与带头结点的链表

|      | 无头结点<br> | 有头结点                            |
| ---- | -------- | ------------------------------- |
| 表示空表 | 头指针为空    | 头结点的指针域为空                       |
|      |          | 头结点的数据与可以为空或存放表长等附加信息，但头结点不计入表长 |
|      |          | 便于首元结点的处理                       |
|      |          | 统一空表与非空表的处理                     |
4.链表的特点：
只能通过头指针进入链表
顺序存取法：通过每个结点的指针域依次向后顺序扫描其余结点

6.3单链表的销毁(头指针和头结点也无了)
```c++
//从头指针开始依次释放所有结点
//再引入一个指针 L每次指向一个指针 p也指向这个指针 L往后一位然后把它删掉
Status Destroy (LinList &L){
	LNode *p;
	while (L!=nullptr){
		p=L;
		L=L->next;
		delete p;
	}
	return OK;
}
```

6.4 清空链表（空链表，保留头指针和头结点）

```c++
//从首元结点开始释放，将头结点的指针域设置为空
Status Clear(LinkList &L){
	LNode *p,q;
	p=L->next;
	while(p !=nullptr){
		q=p->next;
		delete p;
		p=q;
	}
	L->next =nullptr;
	return OK;
}
```
